# ループ型モデルカード用のメタデータ抽出

## 変更したリポジトリ

## やったこと

収集したモデルカードを解析する箇所に、inkling2_loop や sensenova_loop のようなタグを持つエントリから「ループ回数」「実効アクティブパラメータ」を抜き出す小さな抽出関数を追加してください。重みのダウンロードや推論は行わず、tags と説明文のテキストだけを入力にする。Inkling-2-Mini 風のカードから loop=3 と active≈5B を取得でき、既存の記事生成の入力スキーマを壊さないことをもって完了とする。

## なぜ

今日出たばかりの公開モデルで、writerの記事でも話題のループ型アーキテクチャをニュース収集側がいち早く扱えるようにするため。タグを読むだけなら完全に無料で、収集リポジトリの役割にも合う。
