    このアプリについて

    • 毎日 09:00（マレーシア時間 / UTC+8） に GitHub Actions が自動収集します。
    • ツールは「直近のスター増加ペース × 更新の新しさ」で順位付けしています。
    • 要約は無料枠のAI（Gemini / Groq / OpenRouter / Cloudflare）。キーが無い場合はルールベースで動きます。
    • ホーム画面に追加するとオフラインでも最後に取得した内容を読めます。
