      このアプリについて

      • 毎日 09:00（マレーシア時間 / UTC+8） に GitHub Actions が自動収集します。
      • ゆいまる予測：note の書き手ゆいまるさんの直近記事（RSS）から関心を毎日学習し、当日の全候補（GitHub・HF・ニュース・論文）を採点して「次に記事にしそうなもの」を並べます。既に記事化したものは除外し、翌日以降に実際に記事になったかを自動で答え合わせします。
      • ツールは「予測スコア 65% × スター増加ペース 35%」で順位付けしています。ニュースと最先端マップも予測スコアで並べ替えています。
      • 最先端マップは arXiv・bioRxiv・専門メディア・各社ブログ・GitHub・Hugging Face から分野ごとに拾い、部門ごとに最低1件は載るよう選んでいます。論文は査読前のものを含みます。
      • 要約は無料枠のAI（Gemini / Groq / OpenRouter / Cloudflare）。キーが無い場合はルールベースで動きます。
      • ホーム画面に追加するとオフラインでも最後に取得した内容を読めます。
