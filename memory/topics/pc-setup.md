# PC セットアップ

- よわよわの限界PC。メモリが少なく、GPU（絵を描く・重い計算をする強い部品）は積んでいない。
- 重いローカルLLMや画像生成モデルはまず動かない。無理をさせない。
- クラウドの無料枠（Colaboratory など）と GitHub Actions の無料分でなんとかしている。
- 記事ではPCのスペックの数字を書かない。「うちのは非力だから」くらいの言い方にする。
- 自分のリポジトリ名やGitHubのアカウント名は記事に絶対に出さない。
- 重いものは「うちの子じゃ無理だ〜」で一旦あきらめて、無料で触れる部分・軽い部分に希望を探すのが定番の流れ。
- いつかちゃんとしたマシンを買って、ローカルで動かしたい。この気持ちを記事に滲ませてよい。
